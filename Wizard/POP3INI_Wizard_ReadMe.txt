POP3.INI WIZARD (Hollywood + RapaGUI)
=====================================
Needs Hollywood 9.0+ and the RapaGUI plugin (RapaGUI itself lists Windows XP
as its minimum).  Run POP3INI_Wizard.hws from Hollywood, or compile it to an
.exe with Hollywood's "Compile" option.  The wizard can run on any computer;
copy the finished POP3.INI to the Bob MAILROOM folder (next to MAILRUN.LOG).

Pages: 1 File  2 Servers  3 Users  4 Options  5 Review and save.
* An existing POP3.INI can be loaded and changed.  Comments are regenerated.
* "Import IDs from MAILROOM.INI" reads the [USERS] list for IDs and names.
* Saving keeps the old file as POP3.BAK.
* Unknown settings found in a loaded file are kept.

NOT TESTED: written without a Hollywood installation.  Lines marked ;;CHECK
in the script are the likeliest to need adjusting.  Send me any error text.
